# Goal 7 Execution Loop

1. Reconcile Goal0 and this plan with code and actual evidence.
2. Select the first unfinished stage and advance its concrete delivery/check.
3. Reuse existing native workloads, fixtures, counters and semantic authorities;
   preserve earlier repairs and avoid new testing platforms or nested goals.
4. Verify changed boundaries on actual PostgreSQL, isolate faults/destructive
   work, and measure costs before claiming an improvement.
5. Fold material decisions/results/limits into this plan and Goal0.
6. Continue until the entire product and integrated acceptance hold; reopen a
   capability's owning child for a gap, then return here. No silent exclusions.
7. At a session boundary record unfinished work, last verified result, blocker
   and next action. Do not stop merely because one subtask or benchmark finished.
