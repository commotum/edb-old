# Goal 6 Execution Loop

1. Read Goal0 and this plan; reconcile current code, tests and verified results.
2. Select the first unfinished stage and deliver its next coherent capability.
3. Reuse the native engine, application, codecs, operators and fault fixtures;
   use the local semantic docs and recovered source where relevant.
4. Check semantics/security, actual PostgreSQL and real network/process behavior;
   measure costs and keep failed/unknown outcomes visible.
5. Fold material decisions/results/status into this plan and Goal0. Preserve
   earlier work and all parent requirements; do not silently change scope.
6. Continue until all child signals hold, then return to Goal0 and execute Goal7.
   An integrated gap reopens its owner; no nested or corrective parent goals.
7. At a session boundary leave the active work, last verified result, blocker
   and next concrete action here.
