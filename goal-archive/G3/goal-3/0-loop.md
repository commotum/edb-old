2. Select the first unfinished internal stage; preserve completed repairs.

   meaning and recovered source for design. Do not create nested goal folders.

   for changed boundaries; exercise the application workflow throughout.
5. Fold material decisions, verified outcomes, and remaining gaps into the plan.

   next unfinished child. A scaffold or this child's completion is not Goal 0's end.

   Reopen the owning child if integration exposes a core failure.
