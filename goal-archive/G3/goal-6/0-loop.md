# Goal 6 Execution Loop

1. Sync this plan and Goal 0 with actual code, observed results and completed work.
2. Select the first unfinished stage; take the shortest implementation or real
   deployment check that advances its outcome. Keep this the only active child.
3. Exercise the public application path under declared workload/resource sizes.
   Measure actual memory, range I/O, throughput and recovery; distinguish skipped
   fixtures, semantic counters and real physical observations.
4. Fix discovered core defects in their owning implementation/child without
   creating another parent or weakening acceptance. Preserve prior repairs.
5. Fold material decisions, measured results, limitations and status into this
   plan and Goal 0. Continue through failure/maintenance and final acceptance.
6. Before closure compare the running system with the original objective, run
   relevant integration/regression checks and update actionable run instructions.
   A benchmark or completed child alone does not establish the parent outcome.
7. At an unavoidable session boundary leave the last verified state and precise
   next action; state blockers or uncertainty plainly. Otherwise keep executing.
