# Goal 7 — Execution loop

1. Sync this plan and Goal 0 with current files and verified results.
2. Select the first unfinished internal stage; take the next implementation or
   cleanup step using current evidence. Do not create more goal folders.
3. Preserve shared algorithms and user-visible semantics while deleting displaced
   adapters. Verify source ownership as well as observed behavior.
4. Run focused permanent regressions and actual fresh-target PostgreSQL/application
   checks; at integration run the current suite and dedicated crash workflow.
5. Fold material decisions, costs, removals, failures and status into both plans.
   Do not equate a passing compile, deleted SQL or updated docs with completion.
6. Continue through all stages; reopen owning earlier children for integrated
   gaps. At boundaries leave one concise next-action note and plain uncertainty.
7. Return to Goal 0 for full acceptance. Finish only when the complete cutover,
   cleanup and integrated product work, not merely this scaffold.
