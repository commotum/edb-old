# Goal 7 execution loop

1. Sync `0-plan.md` with actual code/results and Goal0's twelve-finding coverage.
2. Choose the first unfinished internal stage and directly advance its outcome.
3. Reuse the application and regression support; run actual PostgreSQL checks and
   account for complete-path costs. Treat missing prerequisites as missing proof.
4. Repair integration defects in their owning child, keeping one child active;
   then return here. Preserve earlier repairs, durable meaning and exact retries.
5. Fold material decisions, verified results and status into this plan and Goal0;
   keep user-facing acceptance documentation accurate and qualified.
6. Continue until integrated acceptance and the original product objective hold.
   Do not add optional features or convert warning counts into a false finish line.
7. At a session boundary leave the last verified state, next action and exact
   fixture/blocker. Mark Goal0 complete only when no required repair remains.
