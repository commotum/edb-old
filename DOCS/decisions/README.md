Architecture Decisions (ADRs)

- Use this folder to capture significant technical decisions with context and consequences.
- Template (ADR-0001.md):

Title: <short, imperative>
Date: YYYY-MM-DD
Status: Proposed | Accepted | Deprecated | Superseded
Context:
- What problem are we solving? What constraints apply?
Decision:
- The choice made and rationale.
Consequences:
- Positive and negative tradeoffs.
References:
- Links to issues, PRs, background docs.

Start numbering ADRs sequentially (ADR-0001.md, ADR-0002.md, …).
